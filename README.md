# Zombryx · Privacy Policy

Privacy policy of the Zombryx Android game, in 12 languages, published with GitHub Pages:
https://maikel1991p3.github.io/zombryx-privacy/

A language can be opened directly with a hash, e.g. `#es`, `#de`, `#ja`, `#pt-BR`, `#zh-TW`.
Without a hash the page follows the browser language.
